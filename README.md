# 元宝的星星大冒险

这是元宝人生中的第一款小游戏。

## 怎么玩

直接打开 `index.html`，或者用本地服务器打开这个文件夹。

- 左右方向键：移动
- 空格：跳跃，进入河道或海洋后可以向上游
- J：攻击小怪
- K：扔手榴弹，威力 60
- 打败全部怪物后，终点宝箱或出口会解锁
- 收集一个小星星可以获得 60 金币
- 每 10 点经验升 1 级，每升 1 级攻击力翻倍，最大生命值也会增加
- 游戏没有声音，适合安静游玩
- Enter：在主界面开始游戏
- 主界面有测试世界按钮，可以直接进入任意世界测试

## 世界

道路不会结束，关卡会按下面顺序循环：

1. 砾石草原
2. 海洋
3. 沙漠
4. 沼泽
5. 岩浆世界

海洋关卡有潜水员皮肤、珊瑚礁、鱼、螃蟹、鲨鱼和拿鱼叉的海怪。

沙漠关卡有金字塔入口和流沙陷阱，停留 3 秒会被陷进去。

沼泽关卡有沼泽怪物和沼泽陷阱，出口会通往岩浆世界。

岩浆世界有很多岩浆池，需要不停跳跃。这里有岩浆法师、岩浆骑士、岩浆刀手、岩浆士兵、岩浆怪、岩浆史莱姆，以及穿着岩浆铠甲的终极大 BOSS。BOSS 可以躲进岩浆，也会召唤拿着大斧头的铠甲岩浆怪物；如果 BOSS 的斧头卡住，就是攻击机会。

## 职业

开局会赠送 50 金币。主界面可以选择职业：

1. 医生：点击“回复”按钮，立刻回满生命
2. 警察：点击“牢笼”按钮，发射牢笼困住怪物 10 秒
3. 黑拳：点击“黑拳”按钮，短时间内所有伤害无效，可以穿过岩浆

## 商店和背包

商店有武器、潜水员皮肤、马、力量药水、速度药水和医疗包。进入游戏后，右下角可以打开背包。

商店也有抗火药水，2 金币一瓶。使用后 60 秒内可以无视岩浆和尖刺伤害。

宝箱会分别抽取：

- 90% 概率获得“家人是一幅画”，可以卖 300 金币
- 65% 概率获得“黄金手表”，可以卖 100 金币
