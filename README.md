# 元宝的星星大冒险

这是元宝人生中的第一款小游戏。

## 怎么玩

直接打开 `index.html`，或者用本地服务器打开这个文件夹。

- `←` / `→`：左右移动
- `空格`：跳跃，可以跳到绿色平台上
- `J`：攻击小怪
- 小剑打中小怪 3 次可以打败它
- 打败小怪后，后面的宝箱会解锁
- 打开宝箱可以获得 20 金币
- 被小怪碰到 2 次会失败
- `Enter`：重新开始

## 武器升级

死亡后，如果金币够了，失败界面会出现武器店。

升级顺序：

1. 狼牙棒
2. 步枪
3. 散弹枪
4. 火箭筒

武器越强，小怪也会变得更大、血量更多。
