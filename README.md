# 元宝的星星大冒险

这是元宝人生中的第一款小游戏。

## 怎么玩

直接打开 `index.html`，或者用本地服务器打开这个文件夹。

- `←` / `→`：左右移动
- `空格`：跳跃，可以跳到绿色平台上
- `J`：攻击小怪
- `K`：扔手榴弹，威力 60，碰到怪物会立刻爆炸
- 小剑打中小怪 3 次可以打败它
- 打败全部小怪后，后面的宝箱会解锁
- 右上角会显示这一关还剩几只怪
- 打开宝箱可以获得关卡奖励，后面的关卡奖励更多
- 收集一个小星星可以获得 60 金币
- 尖刺陷阱会在你走到下面时掉下来
- 晃动地面会变成岩浆，变成岩浆后只能跳过去
- 被小怪碰到 2 次会回到主界面
- `Enter`：在主界面开始游戏

## 武器升级

死亡后和获胜后都会回到主界面，主界面里可以打开武器商店。

升级顺序：

1. 狼牙棒：10 金币
2. 步枪：30 金币
3. 马：60 金币
4. 火箭筒：100 金币

武器越强，小怪也会变得更大、血量更多。
