# 元宝的星星大冒险

这是元宝人生中的第一款小游戏。

## 怎么玩

直接打开 `index.html`，或者用本地服务器打开这个文件夹。

- `←` / `→`：左右移动
- `空格`：跳跃，进入河道后可以向上游
- `J`：攻击小怪
- `K`：扔手榴弹，威力 60，碰到怪物会立刻爆炸
- 打败全部怪物后，终点宝箱会解锁
- 右上角会显示这一关还剩几只怪
- 打开宝箱可以获得关卡奖励，后面的关卡奖励更多
- 收集一个小星星可以获得 60 金币
- 尖刺陷阱会在你走到下面时掉下来
- 晃动地面会变成岩浆，变成岩浆后只能跳过去
- 被怪物或陷阱伤害 2 次会回到主界面
- `Enter`：在主界面开始游戏

## 职业

开局会赠送 50 金币。主界面可以选择职业：

1. 医生：点击“回复”按钮，立刻回满生命
2. 警察：点击“牢笼”按钮，发射牢笼困住怪物 10 秒
3. 黑拳：点击“黑拳”按钮，短时间内所有伤害无效，可以穿过岩浆

## 商店和背包

商店新增了魔法棒、火焰剑、力量药水、速度药水、医疗包和马。进入游戏后，右下角可以打开背包。

宝箱会分别抽取：

- 90% 概率获得“家人是一幅画”，可以卖 300 金币
- 65% 概率获得“黄金手表”，可以卖 100 金币
